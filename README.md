Address Book
============

Address Book streamlines account address management with a summary list,
focused add/edit forms, and Addressfield-powered rendering.

Requirements
------------
- Addressfield module

Installation
------------
- Install this module using the official Backdrop CMS instructions at
  https://docs.backdropcms.org/documentation/extend-with-modules.
- Enable **Address Book** via Administration > Modules.
- Clear caches to register menu routes and stylesheets.

Configuration
-------------
- Visit a user profile and open the **Address Book** tab to manage entries.
- Use the list page action links to add, edit, remove, or set defaults.
